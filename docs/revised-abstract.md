# Suggested Revised Abstract

This study implements a supervised-polling-station hybrid electronic-voting prototype that stores AES-256-GCM ballot ciphertexts in CouchDB and revision-aware cryptographic proofs in Hyperledger Fabric. TECV performs ledger-to-database existence, revision, and hash checks plus a reverse scan for unproven database records before tallying. In the executed local experiments, TECV detected the injected modification, deletion, and unproven-insertion scenarios, and the honest five-ballot tally matched synthetic ground truth. A separate Fabric 3.1.5 four-orderer SmartBFT experiment committed a transaction with one orderer unavailable and lost liveness in the tested three-orderer-down condition. Component performance was measured for 100, 1,000, and 5,000 ballots; these measurements used real CouchDB but a memory proof adapter and therefore are not Fabric throughput claims. A negative control confirmed that TECV does not establish cast-as-intended voter intent.
